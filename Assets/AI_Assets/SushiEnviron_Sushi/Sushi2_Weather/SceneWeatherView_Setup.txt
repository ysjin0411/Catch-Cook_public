Sushi2 세 가지 저녁 날씨 연결 안내
작성: 2026-11-11

현재 적용된 씬
- Cloudy: Assets/01.Scenes/Sushi 2.unity
- Sunny: Assets/01.Scenes/Sushi 2_Sunny.unity
- Rainy: Assets/01.Scenes/Sushi 2_Rainy.unity
- 기존 SceneWeatherView 클래스는 수정하지 않았으며 새 날씨 전환 MonoBehaviour는 아직 만들지 않았습니다.
- WeatherPresets.json은 실제 연결을 기록한 참고 자료이며 런타임 로더가 아닙니다.
- 아래 상대 경로는 Sushi2_Weather 폴더 기준입니다.

상태별 연결
- Prefabs/PF_Weather_<날씨>.prefab → -----Weather-----/Sushi_<날씨>Evening
- 각 루트에 Sky, Moon, WaterReflection, StoreLighting, WeatherPostProcess를 묶었습니다.
- Cloudy/Rainy는 Clouds3D를 포함하며 Rainy의 달과 달빛 반사는 비활성입니다.
- Rainy에는 RainParticles와 StormLightning이 추가되어 있습니다.
- 공용 HarborWaterSurface의 Renderer에 Materials/Water/M_Water_<날씨>_Evening.mat을 교체 연결합니다.
- 물 재료는 각각 Shaders/S_StylizedWater_SushiSky_<날씨>.shadergraph 복제본을 사용합니다.
  원본 S_StylizedWater_SushiSky.shadergraph는 변경하지 않았습니다.
- WeatherPostProcess는 Profiles/VP_<날씨>_Evening.asset을 사용합니다.
  글로벌 Volume, Priority 20, Weight 1입니다.

카메라와 안개
- Main Camera: SolidColor. 아래 값은 Unity Color의 RGB 0~1 값입니다.
- Sunny: 배경/안개 (0.095, 0.14, 0.25)
- Cloudy: 배경/안개 (0.095, 0.155, 0.225)
- Rainy: 배경/안개 (0.06, 0.12, 0.18)
- 모두 Fog 활성, Linear, Start 65, End 230입니다.
- 실제 하늘은 Sky가 그립니다. 카메라 SolidColor만으로 날씨를 표현하는 구조는 아닙니다.
- 배경색과 안개는 상태 전환 시 한 번 설정하면 됩니다.
- 고정 게임 카메라 구도를 기준으로 제작했습니다.
- 날씨 루트 월드 위치 (0,0,0), 회전 Identity, 스케일 1입니다.
  기존 -----Weather----- 부모 월드 위치가 (-3.52,-7.72,15.87)이므로
  루트 로컬 위치는 (3.52,7.72,-15.87)입니다.
  다른 부모 아래 생성할 때 로컬 위치 0을 임의로 적용하면 배경과 반사 위치가 어긋납니다.

가게 밝기
- 각 루트의 StoreLighting 아래 스폿 조명 4개를 추가했습니다.
- 카운터 왼쪽/오른쪽, 카운터 중앙, 진열장을 비춥니다.
- 날씨 루트가 여러 개 켜지면 조명과 Volume이 겹치므로 하나만 활성화합니다.
- 각 날씨 Volume의 Bloom: Threshold 0.90, Intensity 0.65, Scatter 0.70.
- Color Adjustments: Post Exposure 0.04, Contrast 4, Saturation 3.
- 기존 Lantern Bloom Volume 공유 프로파일은 수정하지 않았습니다.

달, 구름, 바다 조절
- 달은 MoonSphere_Smooth 메시의 실제 구체와 별도 달무리로 구성됩니다.
- Cloudy 달: Materials/Cloud3D/M_Moon3D_Cloudy.mat
  Color (1,0.83,0.69), Brightness 1.85, PatchStrength 0.04.
- Sunny 달: Materials/Cloud3D/M_Moon3D_Sunny.mat
  Color (1,0.97,0.88), Brightness 1.10, PatchStrength 0.04.
- Clouds3D Cube는 3차원 구름 밀도 계산 범위입니다. 구름 이미지를 붙인 카드가 아닙니다.
- SushiCloudRaymarch.shader가 밀도를 샘플링하며 현재 구름 모양은 고정입니다.
- Density는 광학적 두께, Coverage는 생성 기준값이며 높일수록 구름이 줄어듭니다.
- NoiseScale/Seed는 크기와 모양, ShadowColor/LightColor는 명암입니다.
- 달 위치를 옮기면 구름 재료의 MoonPosition도 맞춰야 합니다.
- 물 색: Cloudy Water Tint(_CloudyWaterTint), Sunny/Rainy는 Weather Water Tint(_WeatherWaterTint).
- 기존 _DeepWaterColor/_ShallowWaterColor는 현재 그래프의 조절 항목이 아닙니다.
- 달빛/번개 수면 반사는 수평 메시와 SushiMoonReflection.shader로 만든 고정 구도용 연출입니다.

Rainy 비와 번개
- 기존 가게 프리팹 내부 Sushi_OutdoorRain은 세 씬 모두 비활성입니다.
- Rainy/RainParticles는 별도로 복제한 비 루트이며 SushiRainEffect와 두 파티클을 가집니다.
  향후 날씨 전환에는 이 RainParticles를 연결합니다.
- Rainy 루트를 켜면 비가 시작되고 끄면 파티클이 정리됩니다.
- StormLightning의 SushiStormLightning이 먼바다 번개 선, 구름/하늘 섬광, 수면 반사를 함께 제어합니다.
- 번개는 기존 StormLightning과 추가 StormLightning_02~05, 총 다섯 지점입니다.
- 최초 재생은 각각 2/8/14/20/26초 후이며 각 지점은 28~54초 범위의 서로 다른 무작위 간격으로 반복합니다.
- 각 번개는 약 0.28초의 이중 섬광이며, 구름 섬광 위치와 수면 반사를 각 지점에 맞췄습니다.
- 번개가 겹칠 때 공유 하늘/구름은 가장 강한 섬광을 유지하여 다른 번개의 종료로 꺼지지 않습니다.
- 인스펙터 메뉴 Preview / Trigger Lightning으로 확인하고 Clear Lightning으로 현재 섬광을 제거합니다.
  자동 반복까지 멈추려면 컴포넌트 또는 루트를 끕니다.
- 편집 모드 Preview In Editor가 켜져 있어 정지된 번개 미리보기가 표시됩니다.
- MaterialPropertyBlock을 사용하므로 런타임에 공유 머티리얼을 변경하지 않습니다.
- 가게 전체 노출 대신 먼 하늘/구름과 수면을 번쩍이게 합니다. 천둥 소리는 추가하지 않았습니다.

향후 SceneWeatherView 역할
- 이미 결정된 날씨의 표현만 변경합니다. 날씨 선택과 영업 상태 판정은 분리합니다.
- 상태별 데이터: WeatherType, VisualRoot, WaterMaterial, CameraBackground,
  FogColor/FogRange, 필요한 ParticleSystem/Lightning 참조.
- 이전 VisualRoot를 끄고 새 WaterMaterial을 공용 Renderer.sharedMaterial에 할당합니다.
- 카메라/안개 값을 적용하고 새 VisualRoot 하나만 켭니다.
- Rainy의 비/번개는 루트 활성화에 맞춰 시작/정리되므로 별도 반복 시작 호출은 필요 없습니다.
- 추가 가게 조명과 Volume도 함께 전환됩니다.
- 실제 전환 MonoBehaviour와 게임 날씨 시스템 연결은 별도 구현 대상으로 남겼습니다.

확인한 범위
- 세 씬 각각 플레이 모드 프레임 진행과 실제 카메라 출력을 확인했습니다.
- Sunny/Cloudy 비 0개, Rainy 비 시스템 2개와 입자 발생을 확인했습니다.
- 번개 종료 후 밝기 복구, 루트 비활성 시 비/섬광 제거, 재활성 시 비 재개를 확인했습니다.
- 날씨 셰이더 컴파일과 메시/머티리얼 연결을 확인했습니다.
- 게임 건물/배/캐릭터 비율과 카메라 구도는 유지했습니다.
  생성 이미지에서 바뀐 형태까지 픽셀 단위로 복제한 결과는 아닙니다.
